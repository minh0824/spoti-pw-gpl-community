# GPL Community Edition

This repository is derived solely from `skopevoj/spoti.pw` tag `v0.21.1`, commit
`a08b38b9e293f0893e92ff7a9b7b9d92f903431a`, which was published under GPL-3.0.

## What “free” means here

- Every feature included in `v0.21.1` is available without a donation, supporter account, membership,
  device pass, or Chroma Plus check.
- The source tree contains no `SGPlus`, `plusFeature`, `plusLocked`, Patreon-auth, Plus-device, or
  Chroma Plus server gate.
- The Ko-fi support row remains as an optional way to support the original author. It unlocks
  nothing, and this fork does not show donation prompts automatically.
- Update checks go only to this community repository's GitHub Releases API. They do not contact the
  later Chroma update service and do not send the installation-usage body used by the upstream tag.
